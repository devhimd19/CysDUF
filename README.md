# CysDUF : Database to Deciphereing the Cysteine function post-translational modifications of Domain of Unknown Function
Database to Deciphereing the Cysteine function post-translational modifications of Domain of Unknown Function (DUFs) proteins expressed in various cell organelles curated from diverse taxonomic origin.

Characterization of DUF proteins experimentally is a tedious process and computational methods have been improved as there is a tremendous momentum gained and more functions of DUFs are identified. Although The literature reports the computational methods to identify and annotate the function of DUFs. However,  but there is no proper DUF database is known to the best of our knowledge. to store these functions and annotations. It is known that Cysteine amino acid is highly involved in the entire electron transport chain (ETC). Earlier we reported Cysteine functional annotation for DUF proteins belonging to Cytochrome C Oxidase Subunit II (COX II).   Here we aim to decipher Cysteine functions in ETC and other pathways and create a database for Cys functions involved in these pathways encompassing taxonomic diversity. The pathways considered here are, Electron Transport Chain, Glutathione metabolism, Fatty Acid Oxidation, Uronic Acid Pathway, TCA Cycle (Krebs Cycle), Pentose phosphate pathway, Glycolysis, Fe-S-Cluster Biogenesis and Photosynthesis. The taxonomic kingdoms included in this work are bacteria, archaebacteria, eukaryotes and viruses. We have curated six hundred DUF proteins from a published report (where Cysteine post-translational modifications of the DUF proteins were not annotated) using web-scraping and retaining the data only related to the above pathways. Here we present a database available as web server (need to be updated) for DUFs proteins belonging to namely Glutathione metabolism, Electron Transport Chain, Fatty Acid Oxidation, Uronic Acid Pathway, TCA Cycle (Krebs Cycle), Pentose phosphate pathway, Glycolysis, Fe-S-Cluster Biogenesis and Photosynthesis pathways. Database has been developed by curating the information of the DUF ID. ,The structural information and biological information were extracted from SCOP database using SCOP superfamily ID (available from DUF ID).
